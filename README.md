## Community Service Hub

## Project Description
Community Service Hub is a simple community-based web application developed using HTML, CSS, and JavaScript.
The platform connects community members with local service providers such as plumbers, electricians, cleaners, tutors, painters, and technicians.
Users can register as service providers, browse available services, search and filter providers by county or sub-county, and book services.
The system uses browser localStorage to save provider information dynamically without using a backend database.
# Project Objectives
- Connect local service providers with community members
- Promote digital access to local services
- Allow providers to register and advertise their services
- Enable filtering and searching of services by location
- Create a simple marketplace system using JavaScript
# Features

## User Features

- View available service providers
- Search services by name
- Filter providers by county and sub-county
- Book services
- View provider information

## Provider Features

- Register as a service provider
- Upload profile image
- Add service details
- Select county and sub-county

## Admin Features

- View registered providers
- Delete providers
- Manage providers dynamically
